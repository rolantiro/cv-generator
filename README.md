# CV Generator

Aplikasi web untuk membuat CV (PDF/JPG) per lamaran kerja. Semua proses berjalan di browser; data (foto, kontak, sertifikat) disimpan di browser pengguna dan tidak dikirim ke server mana pun.

Cara pakai: buka halaman, isi tab **Data Diri** dan **Sertifikat** sekali, lalu untuk tiap lamaran cukup isi nama perusahaan dan posisi di tab **Lamaran** dan unduh PDF atau JPG.
